# UI 重设计方案 · 深空极光（Aurora Deep）

目标：把当前「淡、刻板、没激情」的界面升级为 **商业感 + 高端 + 科技感** 的视觉体系，
参考爱企查 / 企查查（数据科技蓝紫）、火山引擎 / 阿里云（深邃渐变 + 发光数据可视化）、
Linear / Vercel（精致排版与微交互），但不牺牲信息密度与长时间使用的舒适度。

配套可视化预览：`docs/ui-redesign-preview.html`（纯静态、零依赖，浏览器直接打开）。

## 1. 现状诊断

- **色彩失语**：`#fafafa` 米白底 + `#e5e5e8` 灰线 + 单一绿色点缀，主按钮是近黑色 `#202123`，
  品牌没有记忆点，绿色既当品牌色又当成功语义色，互相打架。
- **零层级深度**：卡片全是 `1px` 灰边，无阴影、无渐变、无玻璃质感，页面像一张平铺的表格。
- **字体过小过碎**：大量 10–13px 文字，正文 14px，Hero 仅 44px，商业官网气场不足。
- **无视觉锚点**：首页 Hero 只有纯文字，没有产品视觉、数据图形或氛围背景，3 秒内留不住人。
- **无动效**：没有任何 hover 反馈、过渡与入场动画，界面显得「死」。

## 2. 设计策略：双层主题

营销层（着陆页 / 登录注册 / 套餐）用**深色科技风**造势；工作台层（Studio / 会员中心 / 后台）
用**精修亮色**保证长时间创作的舒适度与可读性。两层共享同一套品牌色与圆角/阴影语言。

### 2.1 营销层：深空极光（深色）

| Token | 值 | 用途 |
| --- | --- | --- |
| `bg-deep` | `#070B18` | 页面基底 |
| `bg-raised` | `#0C1326` | 区块抬升 |
| `glass` | `rgba(255,255,255,.05)` + `backdrop-blur` | 玻璃卡片 |
| `line-dark` | `rgba(255,255,255,.09)` | 深色描边 |
| `text-hi` | `#F2F5FF` | 深色层主文字 |
| `text-mid` | `#9AA6C4` | 深色层次要文字 |
| 极光渐变 | `#5B5BF0 → #8B5CF6 → #22D3EE` | 氛围光斑 / 渐变标题 / 主按钮 |

关键手法：

- Hero 背景 = 深空底 + 2~3 个极光径向光斑（模糊 120px、慢速漂移 20s）+ 细网格线 + 微弱噪点，
  营造「数据深空」氛围（火山引擎 / 爱企查同款手法）。
- 标题关键词用渐变文字（`background-clip: text`），副标题 16px 以上、行高 1.8。
- 玻璃拟态卡片：半透明底 + 1px 亮边 + 顶部 1px 高光线，hover 时边框发光并上浮 4px。
- 主按钮：靛紫渐变 + 外发光 `box-shadow: 0 8px 30px rgba(91,91,240,.45)`，hover 发光增强。
- 数据条（「8 条创作工作流 · 任务全程可追踪 · 额度未完成自动退回」）建立商业信任感。
- Hero 下方放「工作台视觉锚点」：用玻璃面板拼一个缩略的任务中心界面 + 视频缩略图，
  让访客 3 秒看懂产品形态（纯 CSS 实现，零图片成本）。

### 2.2 工作台层：曜石灰白（精修亮色）

| Token | 值 | 替换现状 |
| --- | --- | --- |
| `bg` | `#F5F6FA` | `#fafafa`（微调冷调） |
| `panel` | `#FFFFFF` | 不变 |
| `line` | `#E6E8F0` | `#e5e5e8` |
| `brand` | `#5B5BF0`（品牌靛） | 主按钮从 `#202123` 黑改为品牌靛 |
| `brand-ink` | `#4338CA` | hover / 深色文字按钮 |
| `success` | `#12A97B` | 绿色降级为纯语义色 |
| 阴影 | `0 1px 2px rgba(16,24,40,.05), 0 8px 24px rgba(16,24,40,.06)` | 替代纯描边卡片 |

要点：

- 主按钮从「死黑」改为品牌靛渐变，品牌色贯穿导航激活态、进度条、选中 chip、聚焦环。
- 侧边栏从 `#f7f7f8` 换成白底 + 激活项浅靛底（`#EEF0FE`）+ 左侧 3px 品牌色指示条。
- 卡片保留描边但叠加柔和投影，hover 上浮 2px，层级立刻出来。
- 聚焦环统一为 `box-shadow: 0 0 0 3px rgba(91,91,240,.18)`，替代现在的灰色环。

## 3. 字体与排版

- 字阶放大：正文 14 → 14.5px；辅助文字最小 12px（淘汰 10px）；Hero 44 → 60px（移动端 36px）；
  区块标题 26 → 32px。
- 数字用等宽数字（`font-variant-numeric: tabular-nums`）展示价格、额度、任务数。
- 标题收紧字距（-0.02em），正文保持 1.7 行高；中文用 600/700 字重制造对比，避免全局 400。
- 英文小标（eyebrow）保留大写 + 宽字距，但颜色换为品牌靛并配合 12px 尺寸，不再灰到看不见。

## 4. 组件改造清单

- **按钮**：主按钮品牌靛渐变 + 发光阴影；次按钮白底描边 hover 变浅靛底；高度统一 40/48px。
- **卡片**：白卡 = 描边 + 双层柔和阴影 + hover 上浮；玻璃卡（深色层）= 半透明 + 顶部高光线 + hover 发光。
- **套餐卡**：推荐卡用渐变描边（双层背景法）+ 轻微放大 1.03 + 「推荐」渐变徽章，
  价格数字 36px 渐变文字。
- **导航**：着陆页导航滚动后变玻璃拟态吸顶（`backdrop-filter`），工作台侧边栏加品牌指示条。
- **空状态**：不再用灰虚线框，改为品牌色插画位 + 主按钮引导。
- **进度条 / 状态点**：进度条用品牌渐变；状态点带 4px 光晕。

## 5. 动效规范（克制但有生命）

- 通用过渡 `160ms cubic-bezier(.22,.61,.36,1)`；hover 上浮 `translateY(-2px ~ -4px)`。
- 着陆页入场：首屏元素 fade-up 依次错开 60ms；极光光斑 20s 慢漂。
- 滚动入场用 `IntersectionObserver` + CSS class，禁用 JS 时直接可见（渐进增强）。
- 全程尊重 `prefers-reduced-motion`：一键关闭所有位移与漂移动画。

## 6. 可用性红线（美观不能牺牲的）

- 文字对比度全部 ≥ WCAG AA（深色层 `#9AA6C4` on `#070B18` ≈ 7:1，达标）。
- 交互目标 ≥ 40px；表单密度不降低；Studio 操作路径不变，只换皮不改交互逻辑。
- 仪表盘类信息（任务列表、后台表格）保持高密度，不套用深色营销层。
- 暗色玻璃效果仅用于营销层，避免在数据表格上降低可读性。

## 7. 落地路线（按影响面排序）

1. **Phase 1 · 品牌与着陆页**（✅ 已落地，2026-09-07）：重写 `app/globals.css` 的 token 与 `.landing-*` 区块，
   `app/page.tsx` 增加 Hero 视觉锚点、数据条、渐变标题；登录/注册/验证/找回密码页同步深色玻璃氛围。
2. **Phase 2 · 工作台焕新**（✅ 已落地，2026-09-07）：`components/studio-shell.module.css`、
   `components/workflow-surface.module.css`、`app/globals.css` 工作台层换品牌色、阴影、聚焦环；
   交互路径零改动。主按钮全面从死黑换品牌靛渐变，绿色仅保留为成功语义色。
3. **Phase 3 · 后台与微交互**：`.admin-*` 表格与 KPI 卡精修；空状态、骨架屏、滚动入场、
   `prefers-reduced-motion` 收尾。

每阶段都是纯 CSS/TSX 变更，不触碰 `lib/` 业务逻辑、API 与数据层，回归成本低。

## 8. 参考案例速记

- **爱企查 / 企查查**：蓝紫科技色 + 玻璃拟态 + 发光数据卡片 → 我们的营销层配色与卡片语言。
- **火山引擎 / 阿里云**：深空渐变背景 + 网格线 + 光斑 → Hero 氛围。
- **Linear / Vercel**：大字号紧字距标题、克制的微动效、等宽数字 → 排版与动效规范。
- **Stripe**：渐变描边推荐卡、柔和多层阴影 → 套餐卡与亮色卡片层级。
