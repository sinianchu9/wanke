# Wanke Simple Creation Mode / 简单创作模式

## 1. 目标

Wanke 同时保留两种能力：

- **简单模式**：让普通用户尽快开始做视频，不需要理解模型、Provider、Recipe、Shot、LUFS、FFmpeg 等实现细节；
- **高级模式**：完整保留已有的生成方式、主体卡、Recipe、批量候选、Project / Shot、媒体规格、转场、声音、字幕和最终成片能力。

简单模式不是删掉高级能力，而是把复杂度放到系统后面。

当前产品层级：

```text
快速创作
  ↓
我的作品
  ↓ 需要更多控制时
高级创作 / 高级作品工作台
  ↓
真实 Job / Provider / 媒体处理层
```

---

## 2. 默认入口

Wanke 默认打开“快速创作”。

用户只需要完成 5 个问题：

1. 想做什么；
2. 主体是谁 / 是什么；
3. 一句话说明想表达什么；
4. 发到哪里；
5. 大约多长。

然后点击“开始创作”。

默认页面不会要求用户选择：

- 百炼还是万镜一刻；
- 具体模型；
- Recipe；
- Seed；
- LUFS；
- 转码参数；
- Shot ID；
- 媒体编码规格。

这些仍然存在，但属于高级层或系统执行层。

---

## 3. 第一阶段只支持 3 种简单创作

### 3.1 产品广告

### 适合

- 电商商品展示；
- 产品主视觉；
- 单一卖点短广告；
- 社媒产品视频。

### 用户输入

- 一个已保存的产品；
- 一句话卖点 / 视觉要求；
- 发布平台；
- 大约时长。

### 系统自动做

根据总时长，从以下镜头中取 1–4 个：

1. 开场吸引；
2. 产品展示；
3. 卖点表达；
4. 收尾定格。

底层仍然使用产品一致性策略、多参考图片和现有 Provider 路由。

### 不做

- 不自动编造新的产品结构；
- 不一次塞入很多卖点；
- 不替用户自动选择多个候选中的“最佳版本”。

### 使用演示

```text
类型：产品广告
产品：黑色智能手环
要求：突出循环震动提醒和简洁科技感
平台：抖音
时长：10 秒

开始创作
```

系统建立：

```text
作品：黑色智能手环广告
├─ Shot 01 · 开场吸引   5s
└─ Shot 02 · 产品展示   5s
```

每个 Shot 都对应一个真实独立视频 Job。

---

### 3.2 人物短视频

### 适合

- 固定人物短视频；
- 数字角色内容；
- 简单动作 / 场景人物镜头；
- 需要人物身份稳定的连续内容。

### 用户输入

- 一个已保存的人物；
- 一句话动作 / 场景要求；
- 发布平台；
- 大约时长。

### 系统自动做

根据总时长，从以下镜头中取 1–4 个：

1. 人物亮相；
2. 主要动作；
3. 互动镜头；
4. 自然收尾。

底层优先人物脸部、发型、体型和主要服装的一致性。

### 使用演示

```text
类型：人物短视频
人物：女孩 A
要求：走进咖啡店，在门口回头看镜头，轻松自然
平台：小红书
时长：15 秒
```

系统建立 3 个约 5 秒镜头并分别提交。

---

### 3.3 图片变视频

### 适合

- 产品图动起来；
- 场景图增加镜头运动；
- 单张图片做短视频主镜头。

### 用户输入

- 素材库中的一张图片；
- 一句话说明如何运动；
- 发布平台；
- 大约时长。

### 系统自动做

优先保持原图主体和画面关系，只规划自然动作、环境变化和镜头运动。

### 使用演示

```text
类型：图片变视频
图片：产品主图 01
要求：让画面有轻微风吹效果，镜头慢慢推近，主体不要变形
平台：抖音
时长：5 秒
```

系统创建一个 I2V 视频任务。

### 当前边界

简单模式 V1 使用已经进入素材库的图片。一次性本地图片仍可以在“高级创作”中直接选择。

这是入口边界，不代表底层不支持本地图片。

---

## 4. 时长规划

简单模式的“时长”是创作目标，不要求用户分配每个 Shot。

当前稳定规划：

```text
5 秒  → 5
10 秒 → 5 + 5
15 秒 → 5 + 5 + 5
30 秒 → 10 + 10 + 5 + 5
```

多镜头快速作品默认使用 0.5 秒自然淡化，因此最终成片时间会因为镜头重叠略短于源 Shot 总和。

页面使用“大约多长”而不是承诺毫秒级精确时长。

高级工作台可以修改转场策略。

---

## 5. 平台映射

用户只选择发布目标：

```text
抖音 / 小红书 → 9:16
YouTube / 横屏通用 → 16:9
```

简单模式不展示画幅参数。

高级创作仍可以手动选择其他画幅。

---

## 6. 简单模式与 Project / Shot 的关系

简单模式没有建立第二套数据系统。

它直接使用现有生产底座：

```text
用户一句话
  ↓
buildQuickCreationPlan
  ↓
Project
  ↓
Shot 01 / Shot 02 / ...
  ↓
真实 video_generation Job
  ↓
现有 Provider Router
```

因此简单模式创建的作品可以随时进入高级工作台继续修改。

高级工作台创建的 Project 也可以在“我的作品”中用简单方式查看进度。

---

## 7. 一个镜头失败时怎么处理

快速创作逐个创建独立 Job。

例如四个 Shot：

```text
Shot 01 ✓
Shot 02 ✓
Shot 03 ×
Shot 04 ✓
```

Shot 03 提交失败不会撤销另外三个。

“我的作品”会把 Shot 03 显示为“需要处理”。

用户需要更细处理时进入：

- 高级编辑；
- 或任务中心。

现有失败重试逻辑继续复用。

---

## 8. 简单作品页

“我的作品”默认不展示完整 Project 工程界面。

只展示：

- 作品名称；
- 已完成镜头数；
- 每个镜头预览；
- 生成中 / 失败 / 完成；
- 是否可以生成最终视频；
- “高级编辑”入口。

普通用户不需要先理解：

- candidate Job；
- selected_job_id；
- media readiness；
- provider_job_id；
- codec / FPS / LUFS。

---

## 9. 最终视频的自动化边界

简单模式“生成最终视频”会自动完成两个原本需要手工理解的动作。

### 9.1 自动采用唯一成功版本

如果某个 Shot：

```text
只有 1 个成功视频
```

并且还没有手动选定版本，系统自动把它设为采用版本。

### 9.2 多个版本绝不自动猜

如果某个 Shot 有：

```text
版本 A ✓
版本 B ✓
```

简单模式停止，并提示：

```text
有多个可用版本，请先选择你喜欢的版本
```

用户进入高级编辑明确选择。

这个边界保证“傻瓜化”不会演变成系统替用户做不可逆的审美决定。

---

## 10. 自动本机保存

高级成片链要求采用视频先保存到本机，避免 Provider 云端 URL 过期。

简单用户不需要知道这个步骤。

点击“生成最终视频”时，系统自动：

```text
采用版本
  ↓
检查是否已经保存本机
  ↓ 否
自动 archive
  ↓
现有 Project assembly
```

仍然复用现有安全归档逻辑和文件大小限制。

---

## 11. 最终成片复用已有复杂能力

简单模式没有重新实现成片。

最终仍走：

```text
采用 Shot
  ↓
本机归档
  ↓
媒体规格统一
  ↓
Project 转场
  ↓
声音 / BGM / LUFS
  ↓
字幕轨
  ↓
最终 MP4
  ↓
ffprobe 验证
```

简单模式只是使用默认值或当前 Project 设置，不向普通用户展示全部参数。

---

## 12. 简单模式默认值

### 快速创作

- 分辨率：1080P；
- 版本数：每个 Shot 1 个；
- 多镜头转场：0.5 秒淡化；
- Provider：使用已有全局 Provider Router；
- 模型：由现有生成链处理；
- 产品 / 人物参考：复用主体卡图片；
- 图片变视频：复用选中的素材图片。

### 最终成片

- 声音：使用 Project 当前设置；未配置时沿用系统默认响度；
- BGM：不会自动选择音乐；
- 字幕：使用 Project 当前设置，默认关闭；
- 转场：快速创建的多镜头 Project 默认自然淡化；高级工作台可修改。

---

## 13. 简单与高级功能的职责边界

### 快速创作

回答：

> 我想做什么视频？

负责：需求 → 自动作品计划 → 提交镜头。

### 我的作品

回答：

> 做到哪了？结果怎么样？能不能出片？

负责：进度、预览、最终成片。

### 高级创作

回答：

> 这一条具体怎么生成？

负责：生成方式、Recipe、参考素材、批量候选等。

### 高级作品工作台

回答：

> 这个作品每个 Shot 到底怎么组织和精修？

负责：候选、定稿、排序、媒体诊断、转场、声音、字幕和成片历史。

### Provider Router

回答：

> 最后由哪个服务 / 模型执行？

这是执行层，不是普通用户的创作决策。

---

## 14. 当前明确不做

简单模式 V1 暂时不做：

- 20+ 创作模板；
- AI 自动判断所有作品类型；
- 自动选择 BGM；
- 自动选择多个候选中的“最佳”；
- 自动烧录视觉字幕；
- 自动对白 ducking；
- 多轨 NLE；
- 复杂时间线编辑。

先把三个高频入口做清楚，比继续往首页堆功能更重要。

- [x] 每个 Shot 是独立真实 Job；
- [x] 单个 Shot 失败不撤销其他 Shot；
- [x] 平台自动映射画幅；
- [x] 时长自动拆镜；
- [x] 我的作品默认使用简化页面；
- [x] 高级 Project 工作台完整保留；
- [x] 唯一成功版本可以自动采用；
- [x] 多成功版本绝不自动猜；
- [x] 简单成片自动归档采用视频；
- [x] 最终成片复用已有转场 / 声音 / 字幕 / assembly；
- [x] 普通侧栏隐藏 Provider / Region / Endpoint 等工程状态；
- [x] 缺少最终成片系统工具时给普通用户业务化提示；
