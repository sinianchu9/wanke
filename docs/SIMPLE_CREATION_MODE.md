# Wanke Simple Creation Mode / 简单创作模式

## 定位

Wanke 同时保留：

- **简单模式**：普通用户从第一次输入一路完成到最终视频；
- **高级模式**：完整控制生成方式、Recipe、主体、多参考、Project / Shot、候选、媒体规格、转场、声音、字幕和成片参数。

简单模式不是缩水版，而是现有完整能力上面的业务编排层。

完整闭环规则、失败恢复、自动保存、跨 Provider 本机图片处理和使用演示，以 [`SIMPLE_CREATION_CLOSURE.md`](./SIMPLE_CREATION_CLOSURE.md) 为准。

---

## 默认产品层级

```text
快速创作
  ↓
我的作品
  ↓ 需要更细控制时
高级创作 / 高级作品工作台
  ↓
真实 Job / Provider / 媒体处理层
```

默认进入“快速创作”。

普通用户只回答：

1. 想做什么；
2. 主体 / 图片是什么；
3. 一句话要求；
4. 发到哪里；
5. 大约多长。

不会要求先理解：

- 百炼 / 万镜一刻；
- 模型名；
- Recipe；
- Shot ID；
- LUFS；
- FFmpeg；
- 编码 / FPS / 媒体规格。

## V1 三个入口

### 产品广告

输入：

- 保存过的产品主体，**或本次直接一张产品图片**；
- 一个核心卖点 / 视觉要求；
- 平台；
- 大约时长。

自动规划：

```text
开场吸引
→ 产品展示
→ 卖点表达
→ 收尾定格
```

按时长只取需要的 1–4 个镜头。

### 人物短视频

输入：

- 保存过的人物主体，**或本次直接一张人物图片**；
- 一句话动作 / 场景要求；
- 平台；
- 大约时长。

自动规划：

```text
人物亮相
→ 主要动作
→ 互动镜头
→ 自然收尾
```

### 图片变视频

输入一张图片 + 一句话运动要求。

图片可以来自：

- Wanke 已有图片；
- 公网图片直链；
- 电脑本地 JPG / PNG / WEBP。

电脑图片如何进入底层由系统自动处理：百炼可走临时直传；Yike 可走现有素材上传 / 登记能力。

## 时长

当前稳定拆分：

```text
5 秒  → 1 × 5s
10 秒 → 2 × 5s
15 秒 → 3 × 5s
30 秒 → 10s + 10s + 5s + 5s
```

多镜头快速作品默认使用自然淡化，所以 UI 使用“大约时长”。

---

## 我的作品

简单作品页直接负责普通用户日常闭环：

- 看每个镜头进度；
- 预览成功结果；
- 查看失败原因；
- 重试失败镜头；
- 再生成一个版本；
- 多候选预览并选择；
- 随时更换采用版本；
- 一键最终视频；
- 重新打开最近成片；
- 区分“当前成片”和“作品改动后的旧成片”。

用户不需要为了普通失败处理跳到高级工作台。

---

## 最终视频

简单模式最终仍复用成熟 Project 成片链：

```text
Shot 采用版本
  ↓
结果本机归档
  ↓
媒体统一
  ↓
Shot 转场
  ↓
BGM / LUFS
  ↓
字幕
  ↓
最终 MP4
```

没有第二套简化 FFmpeg 实现。

## 使用演示

### 产品广告

```text
产品广告
→ 选择电脑里的智能手环图片
→ “突出循环震动提醒，简洁科技感”
→ 抖音
→ 10 秒
→ 开始创作
```

系统创建两个真实独立 Shot / Job。完成后在“我的作品”直接预览并生成最终视频。

### 人物短视频

```text
人物短视频
→ 选择保存过的人物，或直接给一张人物图
→ “走进咖啡店，在门口回头看镜头，轻松自然”
→ 小红书
→ 15 秒
```

系统规划 3 个镜头，优先保持人物身份一致。

### 图片变视频

```text
图片变视频
→ 选择一张产品主图
→ “轻微风吹，镜头缓慢推近，主体不要变形”
→ 5 秒
```

系统使用单镜头 I2V 路线。

---

## 简单 / 高级的边界

简单模式负责“完成一次视频需要发生什么”。

高级模式负责“我想精确控制它怎么发生”。

高级模式可以更复杂，但不能成为修复简单模式日常业务缺口的必经路径。
