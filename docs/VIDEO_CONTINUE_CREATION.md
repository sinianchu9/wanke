# Wanke 结果继续创作

本功能解决的问题是：**用户已经得到一个满意或接近满意的结果，希望从这个结果继续产生新的创作。**

它和“失败重试”“批量版本”“视频延长”“局部重做”是四个不同概念。

## 1. 入口与前提

入口位于：

```text
任务中心
→ 已完成的 AI 视频生成任务
```

只有 `video_generation + succeeded` 才显示继续创作能力。

失败任务不显示继续创作，只显示“重试失败任务”。

## 2. 两种继续方式

### 2.1 再来一个类似版本

用途：

> 当前结果方向是对的，我想在完全相同的创作条件下再得到一个独立候选。

执行逻辑：

```text
原成功 Job
    ↓
复制原 Prompt / Recipe / 素材 / 参数
    ↓
移除原 Batch 成员身份
    ↓
创建新的 child Job
    ↓
重新走 Provider Router
```

这个新任务不是原 Batch 的同级成员，即使原任务来自“版本 1/3”。

它通过 `parentJobId` 与原结果建立关系。

### 2.2 以这个结果继续创作

用途：

> 我希望新的生成真正参考刚才得到的视频，并且给它新的创作要求。

用户必须输入新的 Prompt。

执行逻辑：

```text
原成功视频结果
    ↓
选择一个 output
    ↓
把 output 的云端视频 URL 作为 reference_video
    ↓
输入新的创作要求
    ↓
生成方式切换为 reference_to_video
    ↓
保留原 Recipe
    ↓
创建新的 child Job
    ↓
Provider Router 自动选择支持视频参考的执行路线
```

## 3. 它明确不是什么

### 不是失败重试

重试只用于：

```text
status = failed
```

重试的含义是：

> 上一次没有成功执行，我想用相同参数再执行一次。

成功任务不会再显示“复制参数重跑”作为通用按钮，避免和继续创作混淆。

### 不是批量版本

批量版本发生在第一次提交之前：

```text
一个创作意图 → 一次创建 2–4 个候选
```

继续创作发生在看过结果之后：

```text
选中一个具体结果 → 从它产生新的子任务
```

### 不是视频延长

当前“以结果继续创作”会把完整结果视频作为参考素材。

它不会承诺：

```text
把原视频从第 5 秒无缝继续到第 10 秒
```

真正的 Continue / Extend Video 应该作为单独功能实现，需要明确首尾时序连续性和模型能力。

### 不是局部重做 Retake

当前功能不会替换原视频第 3–5 秒。

Retake 需要：

- 明确时间范围；
- 原视频上下文；
- 新生成片段；
- 替换或拼接规则。

它是后续独立功能。

## 4. 与 Recipe 的关系

继续创作保留原任务的 Recipe。

例如原任务：

```text
Recipe：人物一致
参考：女孩照片
Prompt：女孩走进咖啡店
```

结果完成后继续创作：

```text
新 Prompt：保持人物和整体风格一致，女孩从咖啡店走出并回头看向街道
```

新的任务仍使用“人物一致”Recipe。

原因：Recipe 代表这组内容的稳定创作目标，而不是一次性的 Provider 参数。

## 5. 与 Provider Router 的关系

“再来一个类似版本”和“以结果继续创作”都不会直接指定百炼或万镜一刻。

每个新 child Job 仍重新经过 Provider Router。

尤其是“以结果继续创作”会产生 `reference_to_video + video reference`，因此 Provider Router 会按照当前支持视频参考的路线执行。

## 6. 任务关系

三种关系必须可区分：

```text
原任务
├── 重试失败任务
├── 类似版本
└── 继续创作
```

任务中心通过 `parentJobId` 展示父子关系，并根据 `creationAction` 标记来源语义：

- `retry`
- `similar_variant`
- `continue_from_result`

## 7. 操作演示 A：再来一个类似版本

原任务：

```text
产品广告
黑色手环
镜头缓慢环绕，突出屏幕与表带质感
```

结果已经完成并且方向正确。

操作：

```text
任务中心
→ 打开已完成结果
→ 点击“再来一个类似版本”
```

预期：

```text
原任务
└── 新任务：原任务名 · 类似版本
```

新任务使用原 Prompt、Recipe 和素材，但它是新的独立生成。

## 8. 操作演示 B：以结果继续创作

第一条视频：

```text
女孩走进咖啡店，在门口看向镜头。
```

第一条结果满意。

操作：

```text
任务中心
→ 打开已完成结果
→ “以这个结果继续创作”
→ 新要求：保持人物和整体风格一致，改成侧面跟拍，女孩从咖啡店走出并看向街道
→ 继续创作
```

新任务请求会变成：

```text
jobType = reference_to_video
media = 第一条结果视频
prompt = 新的创作要求
recipe = 原 Recipe
```

## 9. 失败边界

### 结果没有云端 URL

如果只有本机归档文件，没有远端可访问 URL，当前不能直接作为远端模型的视频参考。

UI/API 必须明确报错，不把本地地址伪装成公网素材。

### 云端结果 URL 已过期

Provider 可能返回素材访问错误。

这属于“参考素材不可访问”，不是 Prompt 错误，也不是 Recipe 错误。

### 新 child Job 提交失败

child Job 仍会保存在任务中心并标记失败，用户能看到真实失败原因。

不会覆盖或污染原成功结果。

## 10. 后续关系

结果继续创作完成后，下一步适合推进：

1. 主体卡：把人物 / 产品身份变成可复用资产；
2. Video Extend：真正的视频前后延长；
3. Retake：按时间范围局部重做；
4. Project / Shot：把多个结果组织成作品，而不只是 Job 列表。
