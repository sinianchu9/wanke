# Wanke Shot Sequencing / 成片准备

## 1. 这一阶段解决什么

Project / Shot 第一阶段解决了“任务属于哪个作品、哪个镜头、哪个版本最终采用”。

第二阶段继续解决两个问题：

1. 镜头到底按什么顺序播放；
2. 在真正做时间线或一键拼接之前，项目是否已经具备完整、明确的定稿视频输入。

这一阶段仍然不是 NLE 时间线，也不直接拼接视频。

## 2. Shot 顺序是唯一生产顺序

每个 Shot 都有 `position`。

项目页面提供上移 / 下移操作。服务端收到完整的 Shot ID 顺序后会验证：

- 数量必须与当前项目真实 Shot 数量一致；
- 不能有重复 Shot ID；
- 每一个 Shot 必须属于当前 Project；
- 排序更新在一个 SQLite transaction 中完成。

因此不能通过 API 把别的项目的 Shot 偷偷塞进当前项目顺序，也不会产生一半更新成功、一半失败的顺序。

## 3. 定稿顺序预览

项目页新增“定稿顺序预览”。

它严格按照当前 Shot 顺序显示：

```text
01 · Shot 01 · 产品特写 → 采用视频 A
02 · Shot 02 · 模特佩戴 → 采用视频 B
03 · Shot 03 · 结尾镜头 → 未定稿
```

如果一个 Shot 没有采用版本，会明确显示“未定稿”，而不是自动拿最新任务或第一个成功任务代替。

这条规则很重要：

**成片层只消费用户明确采用的版本，不重新猜候选。**

## 4. 视频预览来源

定稿预览优先使用本机归档结果：

```text
output.archivedFile
  ↓
/api/archive/<file>
```

如果尚未归档，则使用 Provider 返回的 `outputUrl`。

因此页面仍会提醒：云端结果 URL 可能过期，满意结果建议在任务中心保存到本机。

## 5. 成片就绪判断

如果 Project 有 N 个 Shot：

```text
已定稿数 = 有 selectedJobId 的 Shot 数量
未定稿数 = N - 已定稿数
```

页面会显示：

- `已定稿 3/5，还缺 2 个镜头`；或
- `全部镜头已具备成片输入`。

这个状态只表示**输入关系完整**，不表示已经完成最终剪辑。

## 6. 为什么还不直接一键拼接

简单把 MP4 文件 `concat` 并不等于成熟成片能力。

不同生成结果可能存在：

- 分辨率不同；
- FPS 不同；
- 编码器不同；
- 音频采样率不同；
- 有的有音轨、有的没有；
- 9:16 / 16:9 混用；
- 云端 URL 已过期；
- 需要转场、字幕、BGM 或响度归一化。

如果在 Shot 顺序和采用版本尚未稳定时直接做 FFmpeg 拼接，只会把上游混乱带到最后一步。

因此正确顺序是：

```text
Project
  ↓
Shot 顺序
  ↓
每个 Shot 明确采用视频
  ↓
定稿顺序预览
  ↓
媒体规格探测 / 统一
  ↓
最终拼接 / 时间线
```

## 7. 与候选版本的关系

调整 Shot 顺序：

- 不改变候选 Job；
- 不改变 adopted Job；
- 不重新生成视频；
- 不改变 parent/child 血缘。

切换采用版本：

- 不改变 Shot 顺序；
- 不删除旧候选；
- 定稿顺序预览立即改为新的采用视频。

两条职责互相独立。

## 8. 操作示例

```text
Project：智能手环广告

原顺序：
1. 产品特写
2. 模特佩戴
3. 品牌 Logo

发现剧情更适合先出现人物：

点击“模特佩戴”上移

新顺序：
1. 模特佩戴
2. 产品特写
3. 品牌 Logo
```

如果第 3 镜头还没有采用版本：

```text
定稿顺序预览
01 模特佩戴   ✓ 视频
02 产品特写   ✓ 视频
03 品牌 Logo  未定稿

已定稿 2/3，还缺 1 个镜头
```

直到所有 Shot 都有明确采用视频后，项目才进入“全部镜头已具备成片输入”状态。

## 9. 当前明确不做

本阶段不做：

- 自动替用户改变镜头顺序；
- 自动选择候选版本；
- 自动补缺失镜头；
- 拖拽式多轨时间线；
- 自动转场；
- 自动拼接；
- 自动统一视频编码参数。

这些属于下一层“媒体规格统一 + 成片装配”。

## 10. 验收标准

- [x] Shot 顺序持久化；
- [x] 服务端验证完整顺序；
- [x] 排序更新使用 transaction；
- [x] 项目页可上移 / 下移 Shot；
- [x] 定稿预览严格按照 Shot 顺序；
- [x] 未定稿 Shot 明确显示缺口；
- [x] 不自动用其他候选填补缺口；
- [x] 已归档视频优先本机预览；
- [x] 顺序与采用版本职责分离；
- [x] 页面说明下一阶段才进入真正成片装配。
